# PDF 저장 및 재사용 기능

## 요구사항
- [ ] 계산기에서 PDF 업로드 후 "이 PDF를 저장해둘까요?" 팝업
- [ ] Supabase Storage 버킷에 PDF 파일 저장
- [ ] DB 테이블에 메타데이터 저장 (파일명, 업로드일, 용도 등)
- [ ] 이후 PDF 업로드 시 "저장된 PDF에서 선택" / "새로 업로드" 선택지
- [ ] 마이페이지에 "내 PDF 관리" 섹션 추가 (목록 + 삭제)
- [ ] 최대 5개 제한 (초과 시 안내)
- [ ] 로그인 사용자만 저장 가능 (비로그인은 기존과 동일)
- [ ] 기존 PDF 파싱/계산 로직 불변

## 구현 계획

### Block 1: DB + Storage 인프라 (Supabase MCP)
1. Storage 버킷 `user-pdfs` 생성 (private, 10MB 제한)
2. `saved_pdfs` 테이블 생성:
   ```sql
   id uuid PK default gen_random_uuid()
   user_id uuid NOT NULL references auth.users(id) ON DELETE CASCADE
   file_name text NOT NULL        -- 원본 파일명
   storage_path text NOT NULL     -- Storage 경로
   file_size integer              -- 바이트
   created_at timestamptz default now()
   ```
3. RLS: 본인 row만 CRUD

### Block 2: 프론트 유틸 + 타입 (2파일)
1. `types/supabase.ts`에 SavedPdf 타입 추가
2. `lib/pdfStorage.ts` 생성:
   - `uploadPdf(file, userId)` → Storage 업로드 + DB insert
   - `listPdfs(userId)` → 목록 조회
   - `downloadPdf(storagePath)` → File 객체 반환
   - `deletePdf(id, storagePath)` → Storage + DB 삭제
   - `countPdfs(userId)` → 개수 확인 (5개 제한)

### Block 3: PdfSourceSelector 컴포넌트 (1파일)
1. `components/calc/PdfSourceSelector.tsx`:
   - 로그인 상태 확인 → 비로그인이면 기존 드롭존만 표시
   - 저장된 PDF 있으면: 선택 탭 (저장 목록 / 새 업로드)
   - 저장된 PDF 없으면: 새 업로드 드롭존만
   - 업로드 완료 후: "이 PDF를 저장해둘까요?" 바텀시트
   - Props: `onFileSelect(file: File)`, `accentColor`

### Block 4: 4개 계산기 페이지에 적용 (4파일)
- 기존 드롭존 + fileRef → PdfSourceSelector 교체
- onPdfSelect / handleFileChange 로직 불변
- PdfSourceSelector가 File 객체를 그대로 전달

### Block 5: 마이페이지 + 검증 (2파일)
1. `components/mypage/SavedPdfList.tsx`: 목록 + 삭제 UI
2. `pages/MyPage.tsx`: SavedPdfList 섹션 추가

## 리스크
- Supabase Storage RLS 설정 누락 시 다른 유저 PDF 접근 가능 → 반드시 검증
- 파일 크기 제한 미설정 시 대용량 업로드 → 10MB 제한 적용
- 기존 onPdfSelect에 File 객체 전달하는 인터페이스 불변 유지 필수
