Notion, GitHub, Vercel MCP 활성화

📓 Notion MCP 토큰 필요

Integration Token 발급 방법:

  1. 아래 버튼 클릭하여 Notion Integrations 페이지 열기
  2. "New Integration" 버튼 클릭
  3. Name: CATCH Development
    Associated workspace: 본인 워크스페이스 선택
  4. "Submit" 클릭
  5. "Internal Integration Secret" 복사 (secret_... 형태)
  6. 아래 입력란에 붙여넣고 저장
  7. 중요: Notion 페이지에서 "..." → "Add connections" → "CATCH Development" 연결
🔗 Notion Integrations 열기
⚠️ Integration 생성 후 반드시 "📋 CATCH 개발 태스크" Notion 페이지에 Integration을 연결해야 합니다!

🐙 GitHub MCP 토큰 필요

Personal Access Token 발급 방법:

  1. 아래 버튼 클릭하여 GitHub Tokens 페이지 열기
  2. "Generate new token" → "Generate new token (classic)" 선택
  3. Note: CATCH MCP Integration
    Expiration: No expiration (또는 1년)
  4. Select scopes:
    • ✅ repo (모든 하위 항목)
    • ✅ workflow
    • ✅ read:org
  5. "Generate token" 클릭
  6. 생성된 토큰 복사 (ghp_... 형태)
  7. 아래 입력란에 붙여넣고 저장
🔗 GitHub Tokens 열기

▲ Vercel MCP 인증 필요

Vercel CLI 인증 방법:

  1. PowerShell 또는 터미널 열기
  2. 아래 명령어 실행:
    npx vercel login
  3. 이메일 주소 입력
  4. 이메일로 받은 확인 링크 클릭
  5. 인증 완료!
⚠️ Vercel은 별도 토큰 파일이 아닌 CLI 인증을 사용합니다. 위 명령어만 실행하면 됩니다.

✅ 설정 완료 후

  1. VSCode에서 Ctrl+Shift+P → "Reload Window" 실행
  2. Claude Code 재시작
  3. MCP 서버들이 자동으로 활성화됨
  4. 테스트 명령어:
    • "Notion CATCH 개발 태스크에서 진행 중인 작업 보여줘"
    • "GitHub에서 최근 커밋 5개 보여줘"
    • "Vercel 배포 상태 확인해줘"
