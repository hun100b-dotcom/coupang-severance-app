🔐 Supabase Database 비밀번호 확인

마이그레이션 실행을 위한 DB 비밀번호 가져오기

1️⃣ Supabase Database Settings 열기

아래 버튼을 클릭하여 Supabase Database 설정 페이지를 엽니다.

🔗 Database Settings 열기

2️⃣ Database Password 확인

  1. Database Settings 페이지가 열리면 스크롤 다운
  2. "Database Password" 섹션 찾기
  3. 비밀번호가 표시되어 있으면 복사
  4. 비밀번호가 없거나 잊어버렸다면 "Reset Database Password" 버튼 클릭
  5. 새로 생성된 비밀번호를 복사 (⚠️ 한 번만 표시되므로 꼭 저장)

3️⃣ 환경 변수 설정 및 마이그레이션 실행

복사한 비밀번호를 아래 명령어의 YOUR_PASSWORD 부분에 붙여넣고 실행하세요.

⚠️ PowerShell에서 실행하세요 (CMD가 아님) 
$env:SUPABASE_DB_PASSWORD="YOUR_PASSWORD"
python run_migrations_simple.py

💡 YOUR_PASSWORD를 실제 비밀번호로 교체한 후 PowerShell에 붙여넣으세요.

✅ 완료 후

마이그레이션이 성공적으로 실행되면 터미널에 성공 메시지가 표시됩니다.

  • ✓ profiles 테이블에 marketing_sms, marketing_email, marketing_phone 추가됨
  • ✓ user_access_logs 테이블 생성됨
  • ✓ RLS 정책 및 인덱스 적용됨
