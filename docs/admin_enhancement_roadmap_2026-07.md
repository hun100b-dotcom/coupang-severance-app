## 3-a. UTM 필요성 판단 (종훈님 "왜 필요하냐")
- **UTM이 하는 일**: 홍보 링크 끝에 `?utm_source=kakao&utm_campaign=여름`처럼 꼬리표를 달면,
  방문자가 **어느 채널(카카오/블로그/인스타/문자 등)·어느 캠페인으로 들어왔는지** 구분해 집계됨.
  referrer(직전 페이지)만으론 카카오톡 인앱·앱 링크 등에서 출처가 사라져 안 잡히는데, UTM은 링크에
  직접 심어 확실히 남김.
- **왜 유용**: "이번 카카오 홍보로 방문 N명, 그중 계산 M명" 식으로 **마케팅 효과를 숫자로** 볼 수 있음.
  채널별 성과 비교 → 잘 되는 채널에 집중. B2C 성장·유료화 준비 단계에서 값이 큼.
- **유지비**: 매우 낮음. 컬럼 4개 + 프론트 캡처 + 집계 섹션이 이미 구현·검증 완료. 추가 운영 부담 없음
  (링크에 UTM 안 붙이면 그냥 "직접 방문"으로 잡히고 캠페인 섹션만 빈 상태).
- **판단(제거 vs 유지)**: **유지 권장.** 구현이 끝났고 유지비가 사실상 0이며, 마케팅 시작 시 바로 쓸 수 있음.
  지금 당장 캠페인을 안 돌리면 화면엔 "아직 캠페인 유입 없음"만 보이므로 방해도 안 됨. 나중에 홍보 시작 →
  즉시 채널별 효과 측정 가능. **단, 종훈님이 마케팅 계획이 전혀 없다면** 대시보드 단순화를 위해 캠페인
  섹션만 숨김 처리하는 것도 가능(데이터 수집은 유지, 표시만 off). 최종 표시 여부는 종훈님 판단.

## 3-b. 운영 가이드 (UTM 사용법 · 리뷰어 B 권고)
- **캠페인 링크는 리다이렉트 없는 공개 경로에 UTM을 붙일 것**. 예: `https://catch-daily-worker.vercel.app/?utm_source=kakao&utm_campaign=여름` (루트 `/`=랜딩, 리다이렉트 없음) 또는 `/guide`, `/severance` 등. `/home`은 비로그인 시 `/`로 리다이렉트되며 그 과정에서 UTM이 유실될 수 있음(첫 진입 캡처 실패).
- **utm_source 는 소문자 권장**(백엔드가 소문자 정규화하므로 `Kakao`·`kakao` 동일 집계).
- **anon UTM 스팸(별도 트랙)**: `visitor_logs` INSERT는 설계상 anon 허용(비로그인 방문 기록용)이라 누구나 임의 utm 행을 넣을 수 있음(기존 위험, 이번 변경이 신규 도입 아님). 캠페인 통계 신뢰도가 중요해지면 rate-limit 또는 서버 프록시 수집으로 하드닝 검토.
