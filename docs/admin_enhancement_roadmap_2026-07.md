## 4. 하지 말아야 할 것 (가드레일)
- 계산 로직(28일 블록 등) 절대 무변경.
- `visitor_logs` insert에 utm 필드 추가는 **마이그레이션 적용 확인 후에만**(안 그러면 방문기록 끊김).
- `admin_accounts`/RLS 정책은 운영 데이터라 변경 전 반드시 실측·승인.
- `X-Admin-Token` 제거는 JWT 전환(P1)과 **동시에** — 먼저 지우면 어드민 전면 잠김.
