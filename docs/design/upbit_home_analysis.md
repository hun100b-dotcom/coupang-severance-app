# 업비트 "홈" 화면 정밀 분석 (거래소 UI 제외)

> **대상**: `https://www.upbit.com/home` 진입 시 보이는 **첫 화면(홈)만**.
> 코인 시세표·차트·주문창 등 **거래소(트레이딩) 기능 UI는 분석 대상에서 제외**합니다.
> 분석하는 것은 **홈의 비주얼 언어** — 레이아웃 골격, 히어로/섹션 구성, 색·타이포·여백 리듬,
> 카드/리스트 정돈, 내비, 정보 위계.
> **근거**: 2026-06-30 라이브 `getComputedStyle` 실측(헥스 = 실측 RGB 환산). 추측 아님.
> **다음 산출물**: `upbit_redesign_worktree.md`(워크트리) → 종훈님 승인 → 홈 시안 코딩.

## 0. 한눈 요약 (비전공자용)

업비트 홈은 **"조용한 청회색 바탕 위에, 흰 면을 헤어라인(가는 선)으로 칸칸이 나누고, 숫자는 작고 또박또박,
포인트는 파랑 하나"** 로 짜인 **차분한 정보 대시보드**입니다.
화려한 그라데이션·큰 그림자·둥근 모서리(토스풍)와 정반대로, **작은 모서리(4px) · 평평한 면 · 높은 정보밀도**가 핵심입니다.

---

## 1. 레이아웃 골격 (위→아래 순서)

```
┌─ ① 헤더 (고정, 높이 80px, 흰색 #FCFCFD) ─────────────────────────────┐
│  [UPbit 로고]   거래소  입출금  투자내역  코인동향  서비스더보기   로그인 회원가입 고객센터 KO │
├─ ② 지표 스트립 (얇은 띠, 배경 #F2F5FA) ──────────────────────────────┤
│  업비트 종합 지수 9,399 +0.20% │ 알트 지수 2,334 +0.31% │ 공포/탐욕 39 공포 │ 24h 1.22조 +9.03% │
├─ ③ 히어로 (2단) ────────────────────────────────────────────────────┤
│  좌: "대한민국 / 디지털 자산 거래소 / 업비트" (36px·700) + [거래소 둘러보기][로그인] + 01/02 캐러셀 │
│  우: 일러스트(세계지도+캔들) / 프로모 배너                                │
├─ ④ 데이터 2단 그리드 ───────────────────────────────────────────────┤
│  좌 2/3: 탭형 시세 프리뷰(1h거래대금·시총·급상승·급하락)  │  우 1/3: 공지사항 리스트 + 안내 배너 │
├─ ⑤ 서비스 탭 (스테이킹 · 코인모으기 · 데이터랩) ─────────────────────┤
├─ ⑥ 푸터 (흰색, 12px, 회사정보·약관·고객센터·앱 다운로드 QR) ──────────┘
```

- **콘텐츠 컨테이너 최대폭 = 1360px** (실측 지배값). 바깥은 전폭, 안쪽 콘텐츠는 1360에 가운데 정렬.
- 모든 섹션이 **같은 1360 컬럼**에 정렬 → 좌측 라인이 일직선으로 떨어지는 **강한 수직 정렬감**.
- 섹션 구분은 **배경 톤 차이(흰↔#F2F5FA) + 헤어라인**으로. 큰 그림자나 카드 띄움 없음.

## 2. 색 팔레트 (홈 실측, 빈도순)

### 2-1. 배경
| 용도 | 헥스 | RGB | 비고 |
|------|------|-----|------|
| 카드·헤더·푸터 | `#FFFFFF` / `#FCFCFD` | 255,255,255 / 252,252,253 | 면의 기본 |
| 페이지 바탕 | `#E9ECF1` | 233,236,241 | 옅은 청회색(흰색 아님) |
| 띠·섹션·표 헤더 | `#F2F5FA` | 242,245,250 | 지표 스트립/구획 배경 |
| 주 CTA·포인트 | `#0062DF` | 0,98,223 | 파랑 |
| 보조 버튼 | `#EDEEF1` | 237,238,241 | 회색 버튼 |
| 강조(지수↑) | `#DD3C44` | 221,60,68 | 빨강(상승) |

### 2-2. 텍스트 (위계가 분명 — 5단)
| 위계 | 헥스 | RGB | 흰 위 대비 | 용도 |
|------|------|-----|-----------|------|
| 본문 주력 | `#333333` | 51,51,51 | 12.6:1 | 일반 본문(가장 많음, 326회) |
| 헤딩/강조 | `#1A2434` | 26,36,52 | 14.8:1 | 제목·남색 잉크 |
| **보조 텍스트** | `#565D6A` | 86,93,106 | **6.7:1** | 라벨·부가설명(AA 통과) |
| 캡션 | `#8E929B` | 142,146,155 | 3.0:1 | 날짜·플레이스홀더(작게만) |
| 비활성 | `#BEC1C6` | 190,193,198 | 1.9:1 | disabled·구분 |
| 포인트 | `#0062DF` | 0,98,223 | 5.5:1 | 링크·강조 숫자 |

> ⚠️ **핵심 교훈**: 업비트도 **읽어야 하는 보조 텍스트엔 `#565D6A`(6.7:1)** 를 쓰고,
> 흐린 `#8E929B`(3.0:1)는 **날짜·플레이스홀더 같은 비필수**에만 제한적으로 씁니다.
> (직전 CATCH 시안이 본문 캡션에 `#8B95A1`을 써 AA 미달이었던 것과 정확히 대비 — 보조텍스트는 #565D6A급으로.)

### 2-3. 보더
- 헤어라인 `#D6D8DB`(214,216,219) ~ `#E1E4EA`. 1px. 면을 나누는 주 수단.

## 3. 타이포그래피 (홈 실측)

- **폰트**: `Roboto, "Noto Sans KR", sans-serif` — 숫자는 **Roboto**로 자릿수 정렬감.
- **스케일(빈도순 실측)**:

| 역할 | 크기/굵기 | 실측 비고 |
|------|----------|----------|
| 히어로 헤드라인 | **36px / 700**, line-height **54px(1.5)** | 색 `#1A2434` |
| 섹션 타이틀 | 20px / 700, 17px / 700, 16px / 700 | 단계적 |
| 본문 | 16 · 15 · 14px / 400 | 가장 많은 대역(14·16·15) |
| 강조 라벨 | 14px / 700, 13px / 700 | 표 라벨·버튼 |
| 캡션 | 12px / 400, 10px / 400 | 메타·날짜 |
| 내비 메뉴 | **12px / 400** | 의외로 작음(밀도) |

- **관찰**: 큰 제목(36)과 작은 본문(12~16)의 **대비가 큼** → 위계가 또렷.
  굵기는 **400(본문) / 700(강조)** 2단으로 단순. 500·600 거의 없음.

## 4. 컴포넌트 패턴

### 4-1. 헤더(글로벌 내비)
- 높이 80px, 배경 `#FCFCFD`, 하단 보더 없음(스크롤 시 생김).
- 로고(좌) + **가로 텍스트 메뉴**(12px, #333) + 우측 액션(로그인=회색칩, 회원가입=파랑버튼).
- 메뉴 hover 시 드롭다운(서비스 더보기).

### 4-2. 지표 스트립
- 4개 **지수 링크**를 한 줄에. 각 `라벨(회색) + 숫자(굵게) + 등락%(빨강/파랑)`.
- 높이 25px대, 띠 배경 `#F2F5FA`. **"중요 숫자를 맨 위에 압축"** — 홈의 시그니처.

### 4-3. CTA 버튼 (실측)
| 종류 | 배경 | 텍스트 | radius | 높이 | 폰트 | 패딩 |
|------|------|--------|--------|------|------|------|
| 주(회원가입) | `#0062DF` | 흰색 | **4px** | 36~40px | 14px/400~700 | 좁음(0 10px) |
| 보조(로그인) | `#EDEEF1` | `#1A2434` | 4px | 36px | 14px | 좁음 |

- **작은 radius(4px) + 좁은 패딩 + 작은 폰트** = 단정하고 압축된 프로 톤.

### 4-4. 데이터 리스트/표
- 흰 면 + 헤어라인 행 구분. 라벨 회색·작게, 값 우측정렬·굵게.
- 카드를 띄우지 않고 **표처럼 평평하게** 나열. (거래소 시세표의 밀도를 홈 프리뷰에도 적용)

### 4-5. 공지 리스트
- 우측 1/3 패널. `제목(남색, 한 줄 truncate) + 날짜(회색, 우측정렬)`.
- "공지사항 >" 헤더 + 더보기 화살표.

### 4-6. 푸터
- 흰 배경, 12px 본문, 회사정보·약관(굵게 강조 일부)·고객센터·앱 다운로드 QR. 정보량 많지만 작고 조용.

## 5. 여백·리듬·질감

- **radius**: 4px 기조(버튼·작은 칩). 큰 패널도 8px 이하. → 각진 프로 인상.
- **그림자**: 거의 없음. 깊이는 **배경 톤(흰/#F2F5FA) + 1px 헤어라인**으로만.
- **그라데이션**: 거의 없음. 히어로 일러스트 정도. 면은 **flat**.
- **정보밀도**: 높음. 한 화면에 [지표 스트립 + 히어로 + 시세 프리뷰 + 공지]가 동시 노출.
- **수직 정렬**: 모든 섹션이 1360 컬럼 좌측 라인에 정렬 → 질서감.
- **컬러 절제**: 화면 대부분 **무채색(흰·회·남색)**, 파랑은 포인트로만, 빨강/파랑은 등락에만.

## 6. 업비트 홈이 주는 "느낌"의 정체 (디자인 원리)

1. **절제된 색** — 무채색 95% + 파랑 포인트 1색 → 신뢰·전문.
2. **또렷한 위계** — 36px 제목 vs 12~14px 본문, 굵기 400/700 2단 → 한눈에 읽힘.
3. **평평한 면 + 헤어라인** — 그림자 대신 선/톤으로 구획 → 차분·정돈.
4. **숫자 우선** — 지표 스트립·우측정렬 숫자 → "데이터를 다루는 곳"이라는 인상.
5. **강한 수직 정렬** — 단일 컬럼 폭(1360) 좌측 정렬 → 질서.

> **CATCH가 빌릴 것**: 위 1~5번 **원리**. CATCH는 거래소가 아니므로 *시세표·차트·주문창 같은
> 거래소 기능 UI는 차용하지 않고*, **홈의 비주얼 언어(절제·위계·평평함·숫자감·정렬)** 만 가져옵니다.
> 빨강/파랑 등락색도 의미(돈은 받는 것=긍정)와 충돌하므로 그대로 쓰지 않습니다(빨강=긴급 전용 보존).

## 7. 직전 시안에서 이미 학습한 함정 (분석 ↔ 구현 연결)

- 흐린 회색(`#8E929B`/`#8B95A1`)을 **본문 보조 텍스트**에 쓰면 AA(4.5:1) 미달 → 업비트처럼 **#565D6A급**으로.
- `grid lg:grid-cols-N`은 모바일 단일컬럼 정의(`grid-cols-1`)가 없으면 자식이 터짐 → 항상 기본 1열 명시.
- 금액 강조색은 `#3182F6`(3.7:1)이 아니라 `#1B64DA`(5.4:1)로 — 흰 위 AA.
