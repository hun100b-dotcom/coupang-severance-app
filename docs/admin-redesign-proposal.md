## 3. 폰트 override 처리전략 + 회귀 자동 측정법 (규칙3 핵심)

### 3-1. 함정 재확인
`index.css:14-24`가 `.text-[10~17px]`·`.text-xs`·`.text-sm`를 **+1.5px !important**로 강제 → 어드민이 인라인 fontSize로 회피 중. **이 override를 직접 건드리면 사용자앱 전 화면 폰트가 변함(회귀 1순위).**

### 3-2. 전략 — "전역 override 무수정 + 어드민 전용 폰트 유틸 신설" (권장)

| 안 | 방법 | 사용자앱 영향 | 채택 |
|----|------|--------------|------|
| A | 전역 override 제거/수정 | 🔴 전 화면 폰트 변동 | ❌ |
| B | 어드민만 인라인 fontSize 유지 | 🟡 현상 유지(정리 안 됨) | △ |
| **C** | **override가 안 잡는 새 클래스** `text-a12/a13/a14/…`(admin 전용)를 tailwind.config에 고정px로 신설 → 어드민은 이 클래스 사용 | **🟢 0(셀렉터 불일치라 전역 override 미적용, 사용자앱 클래스 불변)** | ✅ |

- 핵심: index.css override는 `.text-[12px]` 같은 **특정 리터럴 셀렉터**만 잡음. `text-a12`처럼 **다른 이름**이면 override가 적용되지 않아 **인라인 없이도 크기 확정** + **사용자앱 무영향**.
- 부수효과: 어드민 인라인 fontSize 대량 제거 → 코드 정리(문제#2,#3 동시 해결).

### 3-3. 회귀 자동 측정법 (규칙3)

1. **baseline(변경 전)**: 대표 요소들의 `computed font-size(px)`를 측정·기록.
   - 방법(규칙1 순서): (a) 헤드리스 Playwright `getComputedStyle` (b) 크롬도구 DOM computed (c) 빌드 CSS 정적 파싱로 규칙 계산. 셋 중 가능한 것으로 수치 확보(명령·출력 로그 첨부).
   - 대상: 사용자앱 홈/결과/계산기 대표 텍스트(본문·캡션·헤딩) + 어드민 대표.
2. **after(변경 후)**: 동일 요소 재측정.
3. **판정**: **1px이라도 다르면 자동 FAIL → 즉시 롤백.** 전 항목 일치 시만 PASS. **전/후 수치표 + 측정 명령 + 원본 출력**을 리뷰 보고에 첨부.
4. 특히 **사용자앱 요소는 0px 변화**여야 함(어드민 전용 클래스 전략이라 원칙상 불변 — 측정으로 증명).

## 5. 새 IA · 화면 구성 (Toss/애플급 미니멀 · 소프트섀도우 · FramerMotion)

### 5-1. IA (메뉴 구조는 유지, 셸 재구성)
```
[셸] AdminShell
├─ Sidebar (그룹: 대시보드 / 채용·인원 / 콘텐츠 / 시스템)  ← 헤어라인·활성=brandBg·:hover는 CSS클래스
├─ TopBar (AdminPageHeader: 페이지 제목 + 역할뱃지 + 액션버튼)
└─ Content (max-width 정렬 + staggered-fade 진입)
   └─ 각 메뉴 = [AdminPageHeader] + [필터/툴바] + [AdminTable/카드그리드] + [AdminState 4상태]
```
- **권한별 메뉴 필터링 강화**(현재 가시성=신뢰경계 아님 → 실제 숨김/차단 정합).

### 5-2. 시각 언어
- 카드: 흰 면 + hair 보더 + radius **16** + **soft shadow**(0 1px 2px/0 4px 16px). 모달만 float.
- 표: sunken 헤더 + hairSoft 행 구분 + 숫자 mono/tabular. 밀도 유지하되 여백 통일.
- 버튼/배지: 프리미티브(2장). 무지개 금지(blue/green/회색/의미색만).
- 모션: 메뉴 전환·행 등장 staggered fade(reduced-motion 시 off).

### 5-3. 4상태 표준화
모든 데이터 화면에 **로딩(스켈레톤/스피너) · 성공 · 실패(재시도) · 빈상태(안내)** 일관 적용(AdminState).
