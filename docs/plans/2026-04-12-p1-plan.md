## 작업 2 — 실업급여·주휴수당·연차수당 계산기 E2E 테스트

### 점검 항목

| 항목 | 설명 |
|------|------|
| 라우트 접근 | `/unemployment`, `/weekly-allowance`, `/annual-leave` 정상 렌더 |
| 설문 플로우 | 각 스텝 전진/후진 동작 검증 |
| 간편계산 | 프론트엔드 로직 결과값 검증 (수식 정확성) |
| PDF 정밀계산 | FastAPI 엔드포인트 호출 (`/api/unemployment/precise`, `/api/weekly-allowance/precise`, `/api/annual-leave/precise`) |
| 에러 핸들링 | 네트워크 에러 시 에러 메시지 표시 여부 |
| 로그인 게이트 | 비로그인 시 저장 버튼 → 로그인 유도 |

### 백엔드 API 구조 (현황 파악)

```
POST /api/unemployment/precise     (FormData: PDF + company + insured_days + age_50)
POST /api/unemployment/simple      (JSON: insured_days, avg_daily_wage, age_50)
POST /api/weekly-allowance/precise (FormData: PDF + company)
POST /api/annual-leave/precise     (FormData: PDF + company + used_days + avg_daily_wage)
```

- `api.ts`에서 Axios 인스턴스 통해 호출
- 개발환경: Vite 프록시 `/api/*` → `localhost:8000`
- 프로덕션: `VITE_API_URL` = Render URL

### 영향 파일 목록

| 파일 경로 | 역할 |
|-----------|------|
| `frontend/src/pages/UnemploymentFlow.tsx` | 실업급여 설문·계산 로직 |
| `frontend/src/pages/ResultUnemployment.tsx` | 실업급여 결과 표시 |
| `frontend/src/pages/WeeklyAllowancePage.tsx` | 주휴수당 설문·계산 (간편+PDF) |
| `frontend/src/pages/AnnualLeaveAllowancePage.tsx` | 연차수당 설문·계산 (간편+PDF) |
| `frontend/src/lib/api.ts` | API 호출 함수 정의 |
| `backend/app/api/unemployment.py` | 실업급여 FastAPI 라우터 |
| `backend/app/api/weekly_allowance.py` | 주휴수당 FastAPI 라우터 |
| `backend/app/api/annual_leave.py` | 연차수당 FastAPI 라우터 |
| `e2e/` (신규 생성 예정) | Playwright E2E 테스트 파일 3개 |

### 구현 전략

1. **Playwright MCP 우선** — 기존 Playwright 설정(v1.58.2) 활용
2. **테스트 파일 3개 신규 생성**:
   - `e2e/unemployment.spec.ts`
   - `e2e/weekly-allowance.spec.ts`
   - `e2e/annual-leave.spec.ts`
3. **간편계산 단위 테스트** — 프론트엔드 로직만 검증 (API 목킹)
4. **PDF 정밀계산** — 샘플 PDF 파일로 실제 API 호출 테스트 (백엔드 기동 필요)
5. **에러케이스** — 빈 입력, 잘못된 날짜, API 500 에러 시 UI 검증

### 리스크 평가

| 리스크 | 가능성 | 영향 | 대응 |
|--------|--------|------|------|
| Render 콜드스타트로 API 타임아웃 | 높 | 중간 | E2E 전 워밍업 요청 또는 로컬 백엔드 기동 |
