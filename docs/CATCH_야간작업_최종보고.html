  • ③ 새 어드민 디자인 확인: 어드민에서 Ctrl+Shift+R → 사용자앱과 같은 톤(카드·버튼·배지·모션)으로 바뀜

1. 어드민 "네트워크 에러" — 진짜 원인

여러 메뉴에서 뜨던 Network error의 지배적 원인은 Render 백엔드가 정지된 것이었어(무료시간 소진). 어드민의 설정·로그·감사·회원·지원자 메뉴가 백엔드를 통해 데이터를 가져오는데 서버가 죽어 있으니 동시에 에러가 난 거야. 코드 결함이 아니라 서버 가동 문제.

그와 별개로 코드 레벨의 결함들은 이번에 다 잡았어(아래 2번). 백엔드가 살아나면 이 수정들이 콜드스타트 반복 에러까지 막아줘.
