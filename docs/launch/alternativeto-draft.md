## 서비스 설명 (등재용 영어)

```
CATCH is a free all-in-one benefit calculator for Korean daily and gig workers. It covers four key labor rights: severance pay, unemployment benefits, weekly allowances, and annual leave. 

The app features a proprietary 28-day block algorithm that accurately handles the irregular work patterns common among daily workers at logistics centers (e.g., Coupang, Kurly). Users can upload their PDF payslips for automated parsing and precise calculation, or use the manual input mode for a quick estimate.

CATCH also includes a job listings section for short-term and daily work at major Korean logistics companies, and a personal dashboard to track calculation history.
```

## CATCH만의 차별점

### 1. 28일 블록 알고리즘 (국내 유일)
일용직 근로자의 퇴직금 계산에 적용되는 28일 역산 블록 방식을 자동으로 처리합니다. 마지막 근무일부터 역순으로 28일씩 블록을 나누고, 블록당 8일 이상 근무 여부를 자동 판별합니다. 다른 어떤 서비스도 이 로직을 구현하지 않습니다.

### 2. PDF 임금대장 자동 파싱
쿠팡·컬리 등 주요 물류센터 급여명세서 PDF를 업로드하면 날짜별 근무 데이터를 자동 추출하여 정밀 계산합니다. 직접 날짜를 하나하나 입력할 필요가 없습니다.

### 3. 4종 통합 계산기
퇴직금, 실업급여, 주휴수당, 연차수당을 하나의 앱에서 계산합니다. 각 서비스마다 다른 사이트를 찾아다닐 필요가 없습니다.

### 4. 채용정보 연동
계산 결과 확인 후 바로 새로운 단기 일자리를 탐색할 수 있도록 채용 피드가 통합되어 있습니다. 쿠팡·컬리·CJ 등 주요 물류센터 공고를 실시간으로 확인할 수 있습니다.

### 5. 완전 무료
광고, 유료 플랜, 인앱결제 없이 전 기능을 무료로 이용할 수 있습니다.
