## Description (영어, 200자 이내)

```
CATCH helps Korean daily and gig workers calculate their severance pay, unemployment benefits, weekly allowances, and annual leave — all in one free app. Features a unique 28-day block algorithm for irregular work patterns and PDF payslip parsing for precise results.
```

> 글자 수 확인: 약 265자 → 핵심만 압축한 버전(200자 이내):

```
CATCH is a free calculator for Korean gig workers to claim severance pay, unemployment benefits, weekly allowances, and annual leave. Built with a 28-day block algorithm unique to irregular work schedules, plus PDF payslip parsing for accurate calculations.
```

