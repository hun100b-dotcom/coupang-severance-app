> 광고성 글은 즉시 퇴장 처리되므로, 정보를 먼저 제공하고 자연스럽게 소개하는 방식으로 접근하세요.

## 📲 카카오 오픈채팅 추천 5개

> 카카오톡 → 채팅 → 오픈채팅 → 검색어 입력

### 1. 쿠팡 알바 공식 정보방
- **검색어**: "쿠팡 알바"
- **특징**: 쿠팡 CFS 근무자들이 모여 출근 정보, 급여, 근무 팁 공유
- **활동 전략**: 근무 조건 관련 질문에 답변 → 자연스럽게 CATCH 소개
- **가입 후 첫 메시지**: 아래 `templates_kakao.md` 자기소개 템플릿 사용

### 2. 쿠팡 CFS 물류 커뮤니티
- **검색어**: "쿠팡 CFS"
- **특징**: CFS(쿠팡풀필먼트서비스) 물류 센터 근무자 전용 채팅방
- **활동 전략**: 퇴직금·실업급여 질문에 답변하며 CATCH 링크 자연 제공
- **추천 게시 시점**: 월말(급여 지급 후), 명절 전후, 신규 입사 러시 기간

### 3. 일용직 단기알바 모임방
- **검색어**: "일용직" 또는 "단기알바"
- **특징**: 건설·물류·식품 등 다양한 일용직 종사자
- **활동 전략**: "퇴직금 몰랐는데 계산해보니 OO만원이 나왔습니다" 사례 공유
- **핵심 키워드**: 퇴직금, 실업급여, 주휴수당, 권리 찾기

### 4. 쿠팡 물류 알바 정보 공유
- **검색어**: "쿠팡 물류"
- **특징**: 쿠팡 물류 근무자들의 일정·급여·팁 공유 공간
- **활동 전략**: 급여명세서 관련 질문에 CATCH PDF 분석 기능 소개
- **주의**: 채팅방마다 규칙이 다름 — 입장 후 공지사항 먼저 확인

### 5. 청년 알바 권리찾기
- **검색어**: "알바 권리" 또는 "청년 알바"
- **특징**: 아르바이트 권리, 최저임금, 부당 대우 경험 공유
- **활동 전략**: "쿠팡 HR 출신으로 노동 정보 공유합니다" 자연스럽게 소개
- **CATCH 소개 포인트**: 무료 계산기 + 권리 정보 제공 도구

## 🖥️ 네이버 카페 추천 5개

> 네이버 카페 검색 → 가입 신청 → 활동 등급 쌓기

### 1. 쿠팡알바정보 카페
- **검색어**: "쿠팡알바정보" 또는 "쿠팡알바"
- **카페 규모**: 회원 약 2만~5만 명 (검색 시 규모 확인)
- **활동 전략**:
  - 자유게시판에 퇴직금·실업급여 정보글 게시
  - 댓글로 질문 답변 → 신뢰 축적 → CATCH 소개
- **좋은 게시물 형식**: 정보성 가이드 + "계산기 첨부"

### 2. 마켓컬리·CJ물류 알바 모임
- **검색어**: "마켓컬리 알바", "컬리 알바", "CJ대한통운 알바"
- **카페 특징**: CATCH 타깃 회사(컬리·CJ) 근무자 밀집
- **활동 전략**: 컬리·CJ 급여명세서 PDF 분석이 가능하다는 점 강조

### 3. 일용직 노동자 권리 카페
- **검색어**: "일용직 노동자"
- **카페 특징**: 일용직 법적 권리, 임금 체불, 퇴직금 문의가 많은 카페
- **활동 전략**: 실제 사례와 정보 제공 → CATCH 계산기를 실용 도구로 소개
- **게시 빈도**: 주 1~2회 정기적으로 정보 글 게시 (너무 자주는 홍보로 보임)

### 4. 청년 취업·알바 카페
- **검색어**: "청년 알바", "대학생 알바"
- **카페 특징**: 10~30대 알바생이 주 타깃, 활성화 높음
- **활동 전략**: "아르바이트도 퇴직금 받을 수 있다!" 충격적 정보로 관심 유도

### 5. 노동법 Q&A 카페
- **검색어**: "노동법", "근로기준법"
- **카페 특징**: 노동법 관련 질문·답변 전문 카페, 신뢰도 높음
- **활동 전략**: 정확한 법률 근거와 함께 CATCH를 계산 도구로 소개
- **주의**: 잘못된 정보 제공 시 신뢰 손상 — 반드시 정확한 내용만 게시

## 📅 활동 전략 타임라인

| 기간 | 할 일 |
|------|-------|
| 1주차 | 채팅방 5개 가입, 카페 5개 가입 신청 |
