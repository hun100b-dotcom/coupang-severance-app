# 네이버 프로필 + SNS 자기소개 가이드

```

```

---

## 📝 긴 자기소개 (카페·커뮤니티 프로필)

```
안녕하세요, CATCH 운영자입니다 😊

물류업계 HR·채용 실무를 경험하면서
수많은 일용직 분들의 퇴직금·실업급여 관련 질문을 받았습니다.

"나도 퇴직금 받을 수 있어요?"
"계약 만료인데 실업급여 어떻게 해요?"
"주휴수당이 뭔가요?"

이런 질문들을 보면서 일용직 근로자들이 얼마나 많은 권리를 모르고 있는지 느꼈습니다.

그래서 직접 무료 계산기를 만들었습니다.
CATCH(catch-daily-worker.vercel.app) — 일용직 퇴직금·실업급여·주휴수당·연차수당을
PDF 급여명세서 하나로 자동 계산해줍니다.

앞으로 일용직 권리 관련 정보를 꾸준히 공유하겠습니다.
궁금한 점은 언제든 댓글 남겨주세요!
```

퇴직금·실업급여·주휴수당·연차수당 계산법과 신청법을 쉽게 설명합니다.
