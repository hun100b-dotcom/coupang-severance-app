CATCH 디자인 시스템 레퍼런스

퇴직금 계산기(coupang-severance-app) 실제 디자인 코드 정리 · 재개편 프롬프트용 · 2026-07-01

0. 기술 스택

  • 프론트: React 18 + TypeScript + Vite + Tailwind CSS + Framer Motion → Vercel
  • 백엔드: FastAPI(Python) → Render / DB: Supabase(Postgres, RLS) / 로그인: 카카오·구글 OAuth
  • 스타일 방식: Tailwind 유틸 클래스 + 디자인 토큰(tailwind.config.js) + 전역 CSS(src/styles/index.css). 일부(특히 어드민)는 인라인 style 사용.

2. 타이포그래피

  • 폰트: Pretendard(전역 !important), 숫자·코드는 JetBrains Mono
  • 자간: 큰 제목 타이트(-0.02~0.04em)
  • 숫자 정렬: .tnum(font-variant-numeric: tabular-nums) — 금액·통계에 사용
★ 매우 중요 (재개편 시 반드시 인지): src/styles/index.css가 임의 px 폰트 클래스를 전역 +1.5px로 !important 강제함 (예: .text-[12px]{font-size:13.5px!important}, .text-xs·.text-sm도). → 그래서 어드민은 이 override를 피하려고 인라인 style(fontSize)을 씀. 어드민을 Tailwind 타이포로 옮기려면 이 override부터 정리해야 하고, 잘못 건드리면 사용자 화면 글자 크기가 전부 흔들림(회귀 위험 1순위).

3. 형태 — Radius / Shadow / 글래스

  • 카드 기본 radius: 20px(rounded-xl) · 버튼 rounded-md~lg · 배지 pill
  • 그림자: shadow-card(은은) / shadow-float(플로팅 강조)
  • 글래스(사용자앱 히어로 등): --glass-bg rgba(255,255,255,.72), backdrop-blur ~25px, --glass-shadow
  • 배경: 사용자앱은 AnimatedBackground(blob 메시 그라데이션, index.css @keyframes blob1~5), 어드민은 플랫 up.page

5. 애니메이션 (Framer Motion + index.css)

  • .page-enter / @keyframes pageEnter — 페이지·메뉴 진입 slide+fade
  • .animate-staggered-fade — 순차 등장
  • blob1~5 — 배경 메시 모션 / spinRing(스피너) / pulseDot / copySlideIn·Out
  • Framer Motion — 카드 호버 -translate-y, 모달 트랜지션 등

6. 어드민 전용 (src/shared/adminTheme.ts)

  • UP 객체 — up.* 색을 인라인 style에서 쓰기 위한 JS 상수(hex 동일)
  • RADIUS{sm8·btn12·content16·card20·pill} / SHADOW{card·float} 단일출처
  • CHART_SERIES(차트 색), numeric(숫자 tabular)
  • 어드민 셸: AdminPage.tsx(사이드바 그룹·상단바·접기) + components/admin/menus/*(메뉴별)
