> 2026-04-10 기준 적용된 보안 조치 목록

## ✅ 개인정보 수집 최소화

| 항목 | 상태 | 비고 |
|------|------|------|
| 주민번호 뒤 1자리(성별코드) 미수집 | ✅ 적용 | applicant_gender(남/여 텍스트)로 대체 |
| 주민번호 전체 미수집 | ✅ 적용 | 생년월일(YYYY-MM-DD)만 수집 |
| 신용카드/금융정보 미수집 | ✅ 적용 | 해당 기능 없음 |
| 위치정보 미수집 | ✅ 적용 | region은 자율 입력 (정밀 위치 아님) |
| 휴대폰 본인인증 미연동 | ✅ 채택 안 함 | 법적 필수 아님, 지원 시점 직접 입력으로 데이터 최소화. 추후 필요 시 PASS/NICE 연동 |

## ✅ 접근 통제

| 항목 | 상태 | 비고 |
|------|------|------|
| RLS(행 수준 보안) 적용 | ✅ 적용 | 모든 핵심 테이블 |
| 인증된 사용자만 본인 데이터 조회 | ✅ 적용 | auth.uid() = user_id 정책 |
| 어드민 계정 별도 관리 | ✅ 적용 | admin_accounts 테이블 + X-Admin-Token |
| 슈퍼어드민 계정 제한 | ✅ 적용 | catchmasterdmin@gmail.com 1개 |

| 항목 | 상태 | 비고 |
|------|------|------|

## ⚠️ 보완 권장 사항

| 항목 | 우선순위 | 내용 |
|------|----------|------|
| CORS 도메인 제한 | 중간 | allow_origins를 catch-daily-worker.vercel.app로 제한 |
| 개인정보 자동 파기 | 높음 | 채용 종료 6개월 후 자동 삭제 스케줄러 구현 |
| Supabase 감사 로그 활성화 | 중간 | Supabase 대시보드 → Settings → Audit |
| 휴대폰 번호 암호화 | 낮음 | Supabase Vault로 at-rest 암호화 강화 |
| 개인정보처리방침 공식 게시 | 높음 | 법무 검토 후 /privacy 페이지 업데이트 |
