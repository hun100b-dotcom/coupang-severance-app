## ✅ 산업안전보건법 제29조 근거 (2026-04-11 추가)

### 90일 이내 센터 근무 경험 수집의 법적 근거

**수집 항목**: 지원서 폼 섹션 2 — "해당 센터에서 지난 90일 이내 근무한 경험이 있나요?"

**법적 근거**:
- **산업안전보건법 제29조** (근로자에 대한 안전보건교육)
  - 사업주는 근로자를 채용할 때와 작업내용을 변경할 때 해당 업무와 관계되는 안전보건교육을 실시해야 함
  - "신규 근로자" 여부 판별이 교육 실시 의무의 핵심 기준
  - 통상 **최근 90일 이내 해당 사업장 근무 이력이 없는 경우** 신규 근로자로 분류

**개인정보보호법(PIPA) 근거**:
- 제15조 제1항 제2호: **"법령상 의무를 준수하기 위해 불가피한 경우"** — 별도 동의 없이 수집 가능
- 산업안전보건법 제29조에 따른 교육 실시 의무는 법령상 의무에 해당
- 따라서 이 항목은 **동의 없이도 수집 가능한 법적 근거 확보**

**리스크 평가**:
- **법적 리스크: 낮음** — 법령상 의무 이행 목적의 최소 수집에 해당
- 투명성 차원에서 폼에 "(산업안전보건법 제29조)" 근거 문구 병기 완료
- 수집한 정보는 **안전보건교육 대상 판별 외 다른 목적으로 사용 금지**

**적용 현황**:
- `job_applications.prior_experience_90d boolean` 컬럼에 저장
- 지원서 폼 UI에 근거 법조항 안내 문구 표시
- 어드민 지원자 목록에서 확인 가능

## ✅ 중복 출근 확정 차단 로직 (2026-04-11 추가)

### 같은 날짜 출근 확정 중복 차단

**목적**: 일용직 근로자가 같은 날에 두 곳 이상 출근 확정되는 상황 방지

**구현 방식 (2중 방어)**:

1. **프론트 사전 체크** (`checkConfirmedOnDate` 함수)
   - 지원하기 버튼 클릭 시 → Supabase에서 해당 날짜 + confirmed 상태 지원 조회
   - 충돌 시 모달 열기 전 에러 토스트 표시
   - 메시지: "해당 날짜(YYYY-MM-DD)에 이미 출근 확정된 지원이 있어 추가 지원이 불가능합니다."

2. **DB 레벨 트리거** (`trg_check_no_confirmed_same_day`)
   - `job_applications` 테이블 BEFORE INSERT/UPDATE 트리거
   - 프론트 우회(직접 API 호출 등) 시도 시 DB에서 RAISE EXCEPTION으로 차단
   - 마이그레이션: `2026041102_application_form_expansion.sql`

**주의**: `work_date`가 null인 공고(상시 공고)는 중복 체크 제외
