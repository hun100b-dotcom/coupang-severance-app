## 2. 합의 사항 (두 리뷰어 일치)

1. **무지개색 0건** — Home·ui·TopNav·BottomNav·index.css·tailwind.config 전수 grep + 전 뷰포트 DOM 스캔에서 purple/indigo/violet/amber/cyan 등 0건. 블루+그린(채용)+회색만 사용. (규칙 준수)
2. **반응형 내비 분기 정상** — 데스크톱(md+)=가로 TopNav, 모바일=BottomNav `display:none`↔`block` 전환 확인. 좌우 텅 빔 없음(max-w 1080 중앙정렬).
3. **카드 정렬/baseline 일관** — 채용·계산기 그리드 `items-stretch`+`h-full`로 카드 높이 균일, 통계 3열 균등.
4. **플로팅 카드 비침범** — 데스크톱 히어로 우측 플로팅 카드와 통계 스트립 겹침 없음(floatBottom < stripTop).
5. **마이크로 인터랙션 reflow 무발생** — 전 인터랙션이 transform/shadow/underline만 사용(margin/height 변동 0).
6. **빌드/타입 무결** — `tsc --noEmit` 0에러, `npm run build` 성공.

## 4. 수정 이력

### 1차 수정 (B의 MAJOR + A의 minor)
- 채용 섹션 게이트 `(jobsLoading || jobsError || recentJobs.length > 0)` 제거 → **섹션 상시 렌더**, 내부 4상태(로딩/에러/빈/목록) 모두 도달 가능
- 보조 링크 "왜 CATCH인가요?"·"더 보기" → `min-h-[44px]` 터치 타겟
- 정보성 캡션 `ink-500`→`ink-600`, 푸터 `ink-400`→`ink-500`
- 8pt 정합(Container gap-6/md:gap-8, 히어로 p-6/md:p-8, 가이드 p-6), CardButton hover `-translate-y-0.5`/200ms, 임금 `tabular-nums`

### 2차 수정 (A의 월드클래스 FAIL + B의 min-w-0)
| 항목 | Before | After | 실측 결과 |
|------|--------|-------|-----------|

## 6. 남은 개선점 (비차단 — 후속 화면 작업 시 함께)

1. **녹색 CTA 흰 텍스트 대비** — accent(#06BE7B) 위 흰 텍스트는 대형 텍스트 기준은 통과하나 일반 기준 4.5엔 미달. 채용 브랜드색 정책과 함께 후속 검토(텍스트 그림자 또는 약간 진한 그린).
2. **TopNav 로고/데스크톱 메뉴 높이** — 공통 컴포넌트라 이번 채점 제외. 마우스 환경이라 영향 적으나 동일 원칙으로 후속 정리 권장.
3. **prefers-reduced-motion** — 등장 애니메이션에 감속 옵션 대응(접근성 강화).
4. **320px 5탭 BottomNav** — 극단 폭에서 가로 스크롤(기존 동작, 회귀 아님). 4탭화 등은 별도 논의.
