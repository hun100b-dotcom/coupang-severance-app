## 3. 발견사항

### 🔴 CRITICAL — 없음

기능·로직·빌드·오버플로 관련 치명 결함은 발견되지 않았다 (tsc 0, 오버플로 0 사전검증 신뢰).

### 🟠 MAJOR

**M1. 회색 캡션 `UP.sub`(#8B95A1) 다수가 WCAG AA-Large(3:1)까지 미달 — 저시력 타깃 충돌**
방향문서 §5가 명시한 "작은 폰트는 회색이라도 대비 확보 / 고령·저시력 배려"와 정면 충돌한다.
실측 대비비(계산):

| 사용처 | 색 조합 | 대비 | AA(4.5) | AA-L(3.0) |
|--------|---------|------|:---:|:---:|
| 지표 스트립 라벨 12px (L296) | #8B95A1 / 흰색 | **3.04** | ✗ | △경계 |
| 계산기 부제 12px (L473) | #8B95A1 / 흰 | 3.04 | ✗ | △ |
| 채용 지역·시간 12px (L568) | #8B95A1 / 흰 | 3.04 | ✗ | △ |
| 공지 날짜 11px (L619) | #8B95A1 / 흰 | 3.04 | ✗ | △ |
| 푸터 11px (L647) | #8B95A1 / **page #EEF1F5** | **2.68** | ✗ | **✗** |
| 빈상태 보조문구 (L520) | #8B95A1 / 흰 | 3.04 | ✗ | △ |

→ 12px 이하 일반 텍스트는 AA 기준 4.5:1 필요. 현재 전부 미달이며, **푸터는 청회색 배경 위라 2.68로 AA-Large(3:1)마저 깨진다.**
일용직·고령 핵심 사용자 가독성 리스크. 권고: `UP.sub`를 **#6B7684 전후(흰 위 ≈4.6)** 로 한 단계 어둡게, 푸터처럼 page 배경에 얹는 캡션은 별도로 더 진하게. (업비트가 11px·#666을 쓰는 건 데스크톱 정상시력 트레이더 대상이라 CATCH 타깃과 다름 — 문서도 §5에서 이미 절충 지시함.)

**M2. 채용 임금 숫자 `UP.brand`(#3182F6) 14px가 AA 미달**
L580 `text-[14px] font-black ... color: UP.brand` → 흰 위 대비 **3.71**. bold라도 14px는 'large text'(18.66px↑) 아니라 4.5 필요. 화면에서 가장 중요한 숫자(임금)가 AA 미달. 권고: 이 수치만 `UP.strong`(#1B64DA, 5.41 통과)로.

### 🟡 MINOR

- **m1. 긴급/내일 배지 대비 미달**: '긴급' #F04452 on #FDECEE = 3.26, '내일' #B7791F on #FFF4E5 = 3.35 (L562,565). 10px 텍스트라 AA(4.5) 미달. 배지라 정보 중복(색+위치)이 있어 치명은 아니나, 배지 글자색을 한 톤 진하게 권고.
- **m2. `fig`(대표 수치) 모바일 숨김**: L475 `hidden xs:inline` → 400px 미만에서 '평균 약 250만원' 등 정보가 사라짐. 320px 기기에서 행이 단조로워지는 정도라 허용 가능하나, 의도 확인 필요(누락이 아닌 설계라면 OK).
- **m3. 지표 스트립 구분선 로직 복잡**: L294 `...(i >= 2 ? { borderBottomWidth: 0 } : {})` 인라인 분기 — 모바일 2×2에서 아래줄 보더 제거 의도. 동작은 맞으나 주석이 "구분선" 한 줄뿐, 비전공자(종훈님) 유지보수 관점에서 의도 설명 주석 1줄 추가 권고.
- **m4. 누적 로딩 표기 불일치**: 지표 스트립은 로딩 시 `'…'`(L217), 우측 패널은 스켈레톤 박스(L427). 같은 값의 두 표기가 달라 미세한 비일관. 통일 권고(경미).
- **m5. `/landing` 라우트는 `Navigate to="/"`** (App.tsx L179) — "왜 CATCH인가요?" 클릭 시 홈으로 되돌아옴. 원본도 동일했던 기존 이슈라 이번 리디자인 책임은 아니나, 데드 네비게이션이므로 별도 정리 권고.

### 코드 품질 — 양호

- `any` 남발 없음 (`as JobPosting[]` 1건은 supabase 관행, 원본 동일).
- 한국어 주석 충실 (섹션 헤더 주석·UP 토큰 출처 주석 등 비전공자 친화).
- 토큰 일관성 우수 — 모든 색이 `UP` 객체 경유, 하드코딩 헥스는 배지 배경 일부(#EAF2FE/#FDECEE/#FFF4E5/#EDEEF1)뿐이며 주석으로 맥락 설명됨.
- `hover:bg-[#F4F6F9]` 등 임의값 클래스가 `UP.head`와 중복 표현 — 통일하면 더 깔끔(경미).
