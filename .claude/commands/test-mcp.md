# MCP 서버 전체 테스트

다음 MCP 서버들의 연결 상태와 기본 기능을 테스트합니다:

## 1. Supabase MCP
- `profiles` 테이블 구조 조회
- 최근 레코드 1개 조회

## 2. Notion MCP
- "📋 CATCH 개발 태스크" 페이지 접근
- 최근 태스크 3개 조회

## 3. GitHub MCP
- 현재 레포지토리 정보
- 최근 커밋 5개 조회

## 4. Vercel MCP
- 프로젝트 배포 상태 확인
- 최근 배포 내역

## 5. Playwright MCP
- 설치된 브라우저 확인
- 테스트 파일 목록

---

각 MCP 서버의 응답 시간과 성공/실패 여부를 보고합니다.
