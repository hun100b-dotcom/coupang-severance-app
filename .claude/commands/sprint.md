# Sprint — 기획서 기반 자동 구현

$ARGUMENTS 에 기획서 경로 또는 작업 설명을 전달하세요.

## 실행 순서

### 1단계: 기획서 로딩
- $ARGUMENTS 가 파일 경로면 해당 파일 읽기
- 아니면 $ARGUMENTS 자체를 작업 설명으로 사용
- CLAUDE.md 핵심 규칙 확인 (28일 블록, any 금지, 한국어 주석 등)

### 2단계: 영향 범위 분석
- 변경 예상 파일 목록 나열
- **5개 이상이면 자동으로 작업 분할 제안** → 사용자 승인 전까지 구현 진행 금지 (CLAUDE.md 금지 규칙)
- DB 변경 필요 시 마이그레이션 SQL 먼저 작성

### 3단계: 구현
- 파일별 순차 구현 (한 파일씩)
- 각 파일 완료 시 `npm run build` 또는 `npx tsc --noEmit`으로 즉시 검증
- 빌드 실패 시 즉시 수정 (다음 파일로 넘어가지 마)

### 4단계: 자동 리뷰 호출
- 구현 완료 후 reviewer 에이전트 자동 호출
- reviewer가 FAIL 반환 시 → 수정 → 재호출 (최대 2회)
- 2회 실패 시 사용자에게 보고

### 5단계: 완료 보고
```
## ✅ Sprint 완료

| 항목 | 내용 |
|------|------|
| 작업 | [작업 설명] |
| 변경 파일 | [파일 목록] |
| 리뷰 결과 | [PASS/FAIL] |
| 다음 단계 | [커밋/추가 작업] |
```
