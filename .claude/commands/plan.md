# Plan — 기능 기획서 작성

$ARGUMENTS 에 구현할 기능을 설명하세요.

## 실행 순서

### 1단계: 요구사항 분석
- $ARGUMENTS 파싱
- 관련 기존 코드 탐색 (Glob/Grep)
- CLAUDE.md 제약사항 확인

### 2단계: 기획서 작성

tasks/plans/ 폴더에 아래 형식으로 저장:

```markdown
# [기능명]

## 요구사항
- [ ] 핵심 요구사항 1
- [ ] 핵심 요구사항 2

## 영향 범위
| 파일 | 변경 내용 |
|------|----------|
| path/to/file | 설명 |

## 구현 계획
1. 단계별 구현 순서

## 리스크
- 주의할 점

## 검증 기준
- reviewer가 확인할 항목
```

### 3단계: 승인 요청
- 기획서 내용 출력
- "승인하시면 `/sprint tasks/plans/[파일명]` 으로 구현을 시작합니다" 안내
