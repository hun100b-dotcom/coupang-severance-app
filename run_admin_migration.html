🔧 Admin Accounts 마이그레이션

CATCH 어드민 페이지 탭 정상화를 위한 DB 설정

⚠️ 현재 상태: admin_accounts 테이블이 비어있어 어드민 페이지의 일부 탭이 정상적으로 표시되지 않습니다.
1 Supabase SQL Editor 열기
아래 버튼을 클릭하여 Supabase SQL Editor를 새 탭에서 엽니다.
🚀 Supabase SQL Editor 열기
2 마이그레이션 SQL 복사
아래 SQL을 복사합니다. (코드 블록 클릭 시 자동 복사됩니다)
-- 005_super_admin_setup.sql -- 슈퍼 관리자 초기 설정 및 권한 강화 -- ── 1. is_super_admin 함수 업데이트 ── CREATE OR REPLACE FUNCTION public.is_super_admin() RETURNS boolean LANGUAGE sql SECURITY DEFINER STABLE AS $$ SELECT auth.email() = 'catchmasterdmin@gmail.com' OR EXISTS ( SELECT 1 FROM public.admin_accounts WHERE email = auth.email() AND role = 'super_admin' AND is_active = true ); $$; -- ── 2. admin_accounts role 제약 완화 ── ALTER TABLE public.admin_accounts DROP CONSTRAINT IF EXISTS admin_accounts_role_check; ALTER TABLE public.admin_accounts ADD CONSTRAINT admin_accounts_role_notempty CHECK (char_length(trim(role)) > 0); -- ── 3. system_settings에 신규 키 추가 ── INSERT INTO public.system_settings (key, value, description) VALUES ( 'permission_levels', '{"super_admin":{"label":"슈퍼 관리자","color":"#f04040","permissions":{"dashboard":true,"target":true,"inquiries":true,"notices":true,"members":true,"accounts":true,"settings":true,"audit_logs":true,"server_logs":true}},"admin":{"label":"관리자","color":"#3182f6","permissions":{"dashboard":true,"target":true,"inquiries":true,"notices":true,"members":true,"accounts":false,"settings":false,"audit_logs":false,"server_logs":false}},"viewer":{"label":"뷰어","color":"#6b7280","permissions":{"dashboard":true,"target":false,"inquiries":true,"notices":false,"members":false,"accounts":false,"settings":false,"audit_logs":false,"server_logs":false}}}', '관리자 권한 레벨 정의 (JSON)' ), ( 'member_unmask_key', '', '회원 개인정보 마스킹 해제 보안키' ) ON CONFLICT (key) DO NOTHING; -- ── 4. system_settings anon 읽기 허용 ── ALTER TABLE public.system_settings ENABLE ROW LEVEL SECURITY; DROP POLICY IF EXISTS "system_settings_select_public" ON public.system_settings; CREATE POLICY "system_settings_select_public" ON public.system_settings FOR SELECT USING (true); DROP POLICY IF EXISTS "system_settings_write_admin" ON public.system_settings; CREATE POLICY "system_settings_write_admin" ON public.system_settings FOR ALL TO authenticated USING (public.is_admin()) WITH CHECK (public.is_admin()); -- ── 5. 최초 슈퍼 관리자 등록 ── INSERT INTO public.admin_accounts (email, role, display_name, is_active) VALUES ('catchmasterdmin@gmail.com', 'super_admin', '최고 관리자', true) ON CONFLICT (email) DO NOTHING; -- ── 완료 메시지 ── DO $$ BEGIN RAISE NOTICE '✅ 005_super_admin_setup.sql 마이그레이션 완료'; END $$;
✅ SQL이 클립보드에 복사되었습니다!
3 SQL Editor에 붙여넣기 후 실행
1단계에서 연 Supabase SQL Editor에 복사한 SQL을 붙여넣고 RUN 버튼을 클릭합니다.
4 어드민 페이지 새로고침
마이그레이션이 완료되면 어드민 페이지(https://catch-daily-worker.vercel.app/admin)를 새로고침합니다.

catchmasterdmin@gmail.com 계정으로 로그인하면 모든 탭이 정상적으로 표시됩니다:
  • Dashboard
  • Target
  • Inquiries
  • 공지사항 (Notices)
  • 회원 관리 (Members)
  • 관리자 계정 (Accounts) ← 슈퍼어드민 전용
  • Settings ← 슈퍼어드민 전용
  • Audit Logs ← 슈퍼어드민 전용
  • Server Logs ← 슈퍼어드민 전용
✅ 기대 효과:
• 슈퍼어드민 계정 등록으로 모든 관리자 메뉴 접근 가능
• 권한 레벨 시스템 활성화 (슈퍼어드민/관리자/뷰어)
• 회원 개인정보 마스킹 기능 활성화
• 커스텀 권한 역할 지원
